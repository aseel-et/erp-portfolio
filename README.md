# ERPNext Portfolio — Aseel Etbini

Built with Next.js 14 (App Router), React, Tailwind CSS and Framer Motion.

## Run it
    npm install
    npm run dev        # http://localhost:3000
    npm run build && npm start   # production

## Make it yours (all in data/portfolio.js)
1. Replace every line marked TODO: email, LinkedIn, GitHub, company name, dates.
2. Rewrite the projects with your real work. Fill `client` and `outcome`
   where you can (e.g. "cut month-end close from 5 days to 2"). Empty fields stay hidden.
3. Put your CV at public/cv.pdf.

## Deploy
Push to GitHub, then import the repo at vercel.com. No settings needed.
